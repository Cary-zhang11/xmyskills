# Core 输出模板

```markdown
# {需求名称}测试用例

## {一级业务域}

### {二级功能块}

#### 正常流程功能
- tc-p0-001：{主流程标题}
  - {触发动作或前置条件}
    - {预期结果}

#### 关键分支（顺序）
- {分支维度名称}
  - tc-p1-001：{分支标题}
    - {分支触发条件}
      - {分支预期}
```

## 术语约束
- 统一使用：功能点、关键分支、预期结果、待澄清
- 不混用“流程/路径/route”等异名

## 判定说明
- `p0`：核心业务主链路
- `p1`：关键分支、边界与异常主分支
